# B22NDOW

B22NDOW는 macOS 메뉴바에서 창 배치를 슬롯으로 저장하고 단축키로 불러오는 앱입니다. 현재 열린 창들의 위치와 크기를 그대로 슬롯에 저장해 두었다가, 언제든 단축키 한 번으로 같은 배치를 복원할 수 있어요.

## 다운로드

[**최신 버전 다운로드 (DMG)**](https://github.com/been3p-prog/b22ndow-releases/releases/latest/download/B22NDOW.dmg)

## 설치 방법

1. DMG를 열고 **B22NDOW** 아이콘을 **Applications** 폴더로 드래그.
2. 처음 열 때 macOS 경고 처리:
   - **macOS 15 Sequoia · 26 Tahoe**: "열리지 않음" → 완료 → 시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기 → Touch ID/암호 → 그래도 열기.
   - **macOS 14 Sonoma**: Finder에서 앱 우클릭(control-클릭) › 열기 › 열기.
3. 손쉬운 사용 권한 켜기: 앱 안내 창 → 설정 열기 → 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용 › B22NDOW 스위치 ON.

자세한 안내는 DMG 안의 **처음 열기 전에 읽어주세요.pdf** 를 참고하세요.

## 자동 업데이트

설치 후에는 하루 한 번 새 버전을 자동으로 확인해요. 업데이트가 있으면 알림 창이 뜨고 버튼 한 번으로 설치됩니다. 직접 확인하려면 메뉴바 **B** → **업데이트 확인…**

## 요구 사항

- macOS 14 Sonoma 이상 (14·15·26 지원)
- Apple Silicon 또는 Intel Mac
